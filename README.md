# Library Management System

This project is a Library Management System that uses an SQL database (SQLite). It is developed to manage CRUD (Create, Read, Update, Delete) operations for books, members, and loan records.

## Features
- Adding and listing books.
- Registering new members.
- Borrowing and returning books.

## Setup
1. Clone this repository: `git clone https://github.com/Abdulnafi-c/library-management-system.git`
2. Navigate to the project directory.
3. Run the application: `python main.py`# Library Management System
