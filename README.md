# Library Management System

Bu proje, bir SQL veritabanı (SQLite) kullanan bir Kütüphane Yönetim Sistemidir. Kitap, üye ve ödünç alma kayıtlarının CRUD (Ekleme, Listeleme, Güncelleme, Silme) işlemlerini yönetmek için geliştirilmiştir.

## Özellikler
- Kitap ekleme ve listeleme.
- Üye kaydı oluşturma.
- Kitap ödünç alma ve iade işlemleri.

## Kurulum
1. Bu depoyu klonlayın: `git clone https://github.com/Abdulnafi-c/library-management-system.git`
2. Proje dizinine gidin.
3. Uygulamayı çalıştırın: `python main.py`
